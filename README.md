# Library-Management-System
The Library Management System is a command line based Java application that allows the users to manage a collection of books efficiently. This project demonstrates real world implementation of OOP concepts in Java. 

# Features:
- Add new books to the library
- View all available books
- Borrow a book
- Return a book
- Prevent isuue in already issued books

# Tech Stack:
- Java
- Concepts used:
    - OOP(classes and objects)
    - Encapsulation
    - Arrays for data storage
    - Conditional logic and loops
    - Scanner(for user input)
